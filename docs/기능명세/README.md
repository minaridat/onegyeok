# 기능 명세 — 파일 목록 및 ID 대역표

기존 `Phase1_기능명세서.md` / `Phase2-5_기능명세서.md` 두 파일을 기능(연결 종류)별로 분리했다.
공통으로 적용되는 원칙(비밀번호 미저장, 연결 종료 정책 등)은 `00_공통_기능명세.md`에 모아두고,
각 연결 종류는 자신만의 파일에서 "공통 + 이 연결 종류만의 차이"만 다룬다.

| 파일 | 다루는 범위 | 상태 |
|---|---|---|
| [00_공통_기능명세.md](./00_공통_기능명세.md) | 서버 등록/관리, 서버 관리 테이블, 연결 유지·종료 정책, 보안 아키텍처(ISMS-P) | ✅ 구현 완료 |
| [01_SSH_기능명세.md](./01_SSH_기능명세.md) | SSH 터미널, 인증 재시도, 다중 세션, 동시 입력(Broadcast) | ✅ 구현 완료 |
| [02_SQL_기능명세.md](./02_SQL_기능명세.md) | SQL DB 클라이언트(MySQL/PostgreSQL/MS SQL Server) — 디비버 느낌의 "SQL" 연결 종류 | ✅ 구현 완료 |
| [03_SFTP_기능명세.md](./03_SFTP_기능명세.md) | SFTP/FTP 파일 탐색기 (FileZilla Pro 대체) | ✅ 전송·폴더·동기화·일괄 이름 변경·예약 |
| [04_터미널분할_기능명세.md](./04_터미널분할_기능명세.md) | 탭 내 터미널 분할 — 세션 복제/세션 선택 기반(tmux 비의존) | 🚧 구현 중 |
| [05_RDP_기능명세.md](./05_RDP_기능명세.md) | RDP(원격 데스크톱) 클라이언트 | ✅ 구현 완료 |
| [06_VNC_기능명세.md](./06_VNC_기능명세.md) | VNC 클라이언트 | ✅ 구현 완료 |
| [07_Web_기능명세.md](./07_Web_기능명세.md) | Web 콘솔 URL 등록(북마크) | ✅ 구현 완료 |

## 화면(S) 번호 대역표

새 화면을 추가할 때는 아래에 없는 번호를 쓴다. S4~S6, S11은 의도적으로 비어 있다(S4~S6은 ISMS 정책
변경으로 폐기된 비밀번호 만료 모달 화면, S11은 설계 단계에서 사용되지 않음 — 재사용 금지, 혼동 방지용으로 기록만 남김).

| 번호 | 화면명 | 파일 |
|---|---|---|
| S1 | 메인 화면 | 00_공통 |
| S2 | 서버 등록/수정 모달 | 00_공통 |
| S3 | SSH 터미널 탭 | 01_SSH |
| S7 | 서버 관리(전체 목록/편집) | 00_공통 |
| S8 | 동시 입력 모드(Broadcast) | 01_SSH |
| S9 | SFTP 파일 탐색기 | 03_SFTP |
| S10 | 분할 터미널 레이아웃 | 04_터미널분할 |
| S12 | VNC 세션 뷰어 | 06_VNC |
| S13 | SQL DB 클라이언트 탭 | 02_SQL |

## 기능 ID(F-) 대역표

새 기능을 추가할 때는 자신의 연결 종류 대역 안에서 다음 번호를 쓰고, 다른 대역을 침범하지 않는다.

| 대역 | 연결 종류 | 파일 |
|---|---|---|
| F-101 ~ F-110 | 공통(서버 등록/관리) | 00_공통 |
| F-401 ~ F-403 | 공통(서버 관리 테이블) | 00_공통 |
| F-501 ~ F-502 | 공통(연결 유지·종료) | 00_공통 |
| F-601 ~ F-609 | 공통(보안) | 00_공통 |
| F-201 ~ F-216 | SSH | 01_SSH |
| F-701 ~ F-713 | SFTP/FTP | 03_SFTP |
| F-801 ~ F-808 | 탭 내 터미널 분할 | 04_터미널분할 |
| F-901 ~ F-908 | RDP | 05_RDP |
| F-1001 ~ F-1006 | VNC | 06_VNC |
| F-1101 ~ F-1104 | Web 콘솔 등록 | 07_Web |
| F-1201 ~ F-1206 | SQL | 02_SQL |

> SQL 기능은 원래 F-801~806으로 번호를 매겼다가, 탭 내 터미널 분할(04_터미널분할)이 이미 그 대역을
> 쓰고 있다는 걸 분리 작업 중에 발견해 F-1201~1206으로 재번호했다.
