# 09. 로컬 터미널 · 세션 로그 기능명세

> 대상: SSH 터미널과 같은 xterm 화면을 쓰는 모든 터미널 세션.

## 1. 로컬 터미널

| ID | 기능 | 비고 |
|---|---|---|
| F-1401 | 사이드바 `로컬 터미널` 버튼 또는 `Ctrl+Shift+T`(macOS·Windows 공통)로 이 PC의 셸을 새 탭에 연다 | macOS: 로그인 셸(`$SHELL -l`, 없으면 zsh), Windows: `cmd.exe`(`%ComSpec%`). 시작 폴더는 홈 폴더 |
| F-1402 | 원격 인증이 없으므로 접속 폼·비밀번호 입력이 없다 | 비밀번호 저장 금지 원칙(F-601)과 무관 |
| F-1403 | 같은 탭 화면·동시 입력(브로드캐스트)·스플릿뷰·탭 분리를 SSH 터미널과 동일하게 쓴다 | 렌더러는 SSH 터미널 코드를 그대로 쓰고 메인 프로세스만 PTY(node-pty)로 연결한다 |
| F-1404 | 서버 목록(저장 대상)에는 남기지 않는다 | 사이드바 "로컬" 그룹의 임시 항목 — 앱 재시작 시 사라지고 버튼을 누르면 다시 생긴다 |
| F-1405 | 셸이 끝나면(`exit`) 탭은 남고 "연결이 종료되었습니다"가 표시되며 재연결(↻)로 새 셸을 연다 | |
| F-1406 | 앱 종료 시 모든 로컬 셸을 강제 종료한다 | F-502 |

## 2. 세션 로그

| ID | 기능 | 비고 |
|---|---|---|
| F-1411 | SSH·로컬 터미널 세션에서 **화면에 출력된 모든 내용**(셸이 되돌려 찍는 입력 명령어 포함)을 파일로 자동 기록한다 | 키 입력을 따로 기록하지 않는다 — 비밀번호 프롬프트는 화면에 에코되지 않으므로 비밀번호가 로그에 남지 않는다(F-601). SSH는 셸이 열린 시점부터 기록(접속 프롬프트 단계 제외) |
| F-1412 | 위치: `<userData>/session-logs/YYYY-MM-DD/HHmmss_<이름>_<세션>.log`. 줄마다 `[YYYY-MM-DD HH:mm:ss]` 시각, 시작·종료 줄 포함 | 폴더 0700, 파일 0600(소유자만) |
| F-1413 | 색상·커서 이동 같은 제어 문자는 제거하고 읽을 수 있는 글자로 저장한다 | 줄 편집(덮어쓰기·백스페이스·지우기)을 반영해 zsh/bash의 입력 줄 다시 그리기도 한 줄로 남는다. 프롬프트 아이콘 글리프(Powerline)는 생략 |
| F-1414 | 오른쪽 패널 **세션 로그** 탭에서 날짜별 목록·열람(끝 2MB)·검색(포함된 줄만 표시)·"이 탭 로그 보기"·"로그 폴더 열기"를 제공한다 | 열람 전용 |
| F-1415 | 앱 UI에서 로그를 수정·삭제할 수 없다 | 00_공통 F-605 |
| F-1416 | 기록 켜기/끄기와 보관 기간(30·90·180일, 1년, 기본 90일)을 설정한다. 기간이 지난 날짜 폴더는 앱 시작 시 자동 삭제한다 | 설정은 `<userData>/session-log-config.json` |
| F-1417 | 로그 기록 실패(디스크 오류 등)가 접속·터미널 사용을 막지 않는다 | |

## 3. 범위 밖

- SQL 쿼리·SFTP 전송 내역 로그(별도 기능), 로그 암호화·서명(무결성 보증), 로그 내보내기.
