> 상태: 🔲 설계만 완료, 미구현. 기술 스택(라이브러리 후보 비교)은 [../기술스택/03_RDP_기술스택.md](../기술스택/03_RDP_기술스택.md) 참고.

> RDP 플레이스홀더 pane에 **스크린 캔버스 프리뷰**로 구현되어 있다 — 툴바(클립보드 동기화/전체화면/연결종료) +

> 새로운 화면 설계는 필요하지 않다(기존 `.screen`/`.screen-toolbar`/`.screen-canvas` 마크업·CSS 그대로 사용).

## 1. 화면

새 화면 번호는 필요 없다 — 00_공통의 S1(메인 화면)에서 RDP 서버를 클릭하면 열리는 탭이 곧 RDP 세션 화면이다.

### 와이어프레임 (현재 플레이스홀더, `src/renderer/index.html`에 이미 구현됨)

```
┌───────────────────────────────────────────────────┐
│ win-app-01 · RDP · 1920×1080        [🗐][⛶][⊗]     │
├───────────────────────────────────────────────────┤
│                                                       │
│     ┌──────────────┐                                 │
│     │              │    ┌──────────────────┐         │
│     │              │    │                    │         │
│     └──────────────┘    └──────────────────┘         │
│                                                       │
│ 원격 제어 중 · 지연 24ms                               │
│ ●  ●  ●                                               │
└───────────────────────────────────────────────────┘
```

- 툴바: 서버명 · 해상도 표시, 클립보드 동기화 토글, 전체화면, 연결 종료 아이콘
- 캔버스: 현재는 정적인 "창" 블록(`.win`)으로 원격 화면을 흉내만 냄 — 실제로는 RDP 프레임버퍼를 `<canvas>`에 그리는 자리
- 하단: 지연시간(ms) 배지 + 태스크바 점(원격 쪽 작업표시줄 흉내)

## 2. 기능 명세 (F-901 ~ F-908)

| ID | 요구사항 | 비고 |
|---|---|---|
| F-901 | RDP 프로토콜로 Windows 서버에 원격 데스크톱 접속한다 | FreeRDP 등 연동 — 기술스택 문서의 옵션 A/B/C 참고 |
| F-902 | 해상도를 자동(창 크기에 맞춤) 또는 수동으로 설정할 수 있다 | |
| F-903 | 클립보드 동기화를 켜고 끌 수 있다 | 기본값 on, 툴바 아이콘으로 토글 |
| F-904 | 로컬 드라이브를 원격 세션에 마운트할 수 있다 (선택 기능) | 기본값 off |
| F-905 | NLA(Network Level Authentication)를 지원하며, 인증정보는 저장하지 않고 접속마다 직접 입력한다 | 00_공통 F-601 원칙 — SSH/SQL과 동일하게 탭을 열면 사용자명(선택)·비밀번호 입력 폼을 먼저 보여주고, 성공해야 실제 화면으로 전환 |
| F-906 | 전체화면 전환을 지원한다 | 멀티 모니터 대응은 후순위 |
| F-907 | 연결이 끊기면 자동 재연결을 시도한다 | 01_SSH F-204와 동일 정책(아직 SSH 쪽도 미구현이므로 함께 설계) |
| F-908 | 지연시간(ms) 등 세션 상태를 화면에 표시한다 | 플레이스홀더의 "지연 24ms" 배지 참고 |

## 3. 데이터 모델 추가 (RDP 전용 필드)

```yaml
# Server(00_공통 정의)에 protocol === "rdp"일 때만 사용하는 필드
  rdpResolution: "auto" | string   # 예: "1920x1080"
  rdpClipboardSync: boolean        # 기본 false
  rdpDriveMount: boolean           # 기본 false
```
