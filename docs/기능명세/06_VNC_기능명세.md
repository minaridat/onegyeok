## 3. 기능 명세 (F-1001 ~ F-1006)

| ID | 요구사항 | 비고 |
|---|---|---|
| F-1001 | VNC 서버에 접속해 원격 화면을 표시한다 | noVNC 또는 native 라이브러리 |
| F-1002 | 화면 압축/화질 옵션(예: Tight/ZRLE)을 조정할 수 있다 | |
| F-1003 | VNC는 자체 인증·암호화가 약하므로, **SSH 터널링을 통한 접속을 기본값으로 적용**한다 | 00_공통 F-606과 직접 연결. 터널 불가 시 사용자에게 경고 후 진행 여부 확인 |
| F-1004 | 읽기전용(뷰어 전용, 입력 비활성화) 모드를 토글할 수 있다 | 여러 명이 같은 화면을 볼 때 유용 |
| F-1005 | 화면 스케일링/줌을 지원한다 | |
| F-1006 | VNC 인증(있는 경우 "화면 공유 암호")도 저장하지 않고 접속마다 직접 입력한다 | 00_공통 F-601 원칙 |
