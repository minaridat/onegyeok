## 3. 기능 명세 (F-701 ~ F-713)

| ID | 요구사항 | 비고 |
|---|---|---|
| F-701 | 이미 등록된 SSH 서버 정보를 재사용해 SFTP 세션을 열 수 있다 | 별도 서버 재등록 불필요, 인증 방식/키 파일 경로 공유 |
| F-702 | 로컬 파일시스템과 원격 파일시스템을 듀얼 패널로 동시 탐색할 수 있다 | 각각 독립적인 경로 이동/검색/정렬 |
| F-703 | 드래그앤드롭 또는 컨텍스트 메뉴로 업로드/다운로드할 수 있다 | 다중 선택 지원 |
| F-704 | 여러 전송 작업을 큐로 관리하며 진행률·속도·잔여시간을 표시한다 | 일시정지/재개/취소 가능 |
| F-705 | 원격 파일/폴더의 생성·삭제·이름변경·권한(chmod) 변경이 가능하다 | |
| F-706 | 전송 중 연결이 끊기면 자동 재시도하며, 이어받기(resume)를 지원한다 | 가능한 경우에 한함(서버가 resume 지원 시) |
| F-707 | 비밀번호 인증 서버는 SFTP 접속 시에도 매번 직접 입력한다 | 00_공통 F-601 원칙, 저장 없음 |
| F-708 | 대용량 파일 전송 후 체크섬(SHA-256 등)으로 무결성을 검증할 수 있다 (선택 기능) | 온디맨드, 기본값 off |
| F-709 | 순수 FTP(비-SSH) 서버도 별도 등록해 동일한 듀얼 패널 UI로 접속할 수 있다 | FTP는 평문 프로토콜이므로 FTPS(TLS) 사용을 기본값으로 권장, 평문 FTP는 경고 표시 후 진행 |

| F-710 | 선택 폴더를 하위 폴더와 빈 폴더까지 재귀 업로드/다운로드한다 | 심볼릭 링크 제외, 깊이 64 / 항목 10,000 제한 |
| F-711 | 현재 로컬·원격 폴더를 비교하고 미리보기 후 한 방향으로 파일 동기화한다 | 크기 또는 크기+수정일, 대상 전용 항목 보존 |
| F-712 | 로컬/원격 선택 항목의 이름을 일괄 변경한다 | 문자열 치환·접두사·접미사·순번, 미리보기와 충돌 검사 |
| F-713 | 선택 파일/폴더의 전송 시간을 예약하고 대기 예약을 취소한다 | 활성 세션 한정, 1초~7일, 연결별 최대 20건 |

## 6. 구현 상세와 지원 범위

- 서버 등록의 `SFTP / FTP / FTPS` 종류 안에서 전송 방식과 인증 방식을 선택한다. `fileProtocol`은 `sftp`(기본), `ftps`(explicit TLS), `ftp`(평문), `ftps-implicit`이다. 기본 포트는 각각 22/21/21/990이며 사용자 지정 포트도 가능하다.
- SSH 서버의 연결 정보에서 `SFTP로 열기`를 누르면 사용자명·키 경로 등 등록 정보를 재사용하는 별도 탭이 열린다. 기존 SSH 세션은 유지하고 비밀번호/Passphrase는 SFTP 탭에서 새로 입력한다. 점프 호스트 경유는 아직 지원하지 않는다.
- 로컬/원격 경로 직접 입력, 상위 이동, 경로 조각 클릭, 검색·이름/크기/수정일 정렬을 제공한다. 파일 여러 개를 선택해 전송 버튼 또는 반대 패널로 드래그할 수 있다.
- 폴더를 선택해 파일과 같은 방식으로 전송한다. 하위 폴더·빈 폴더를 유지하고 일반 파일을 기존 큐에 등록한다. 심볼릭 링크와 전송 중간 파일은 제외한다. 기존 폴더를 합칠 때는 덮어쓰기 확인을 받는다.
- 큐는 연결별 순차 실행이다. 진행 바·전송 바이트·속도·잔여시간과 일시정지/재개/취소를 제공한다. 파일 목록·관리 명령도 같은 연결의 전송과 직렬화하므로 전송 중에는 완료를 기다릴 수 있다.
- 전송은 목적 경로 옆의 고유 `.onegyeok-<jobId>.part` 파일에 기록하고, 크기 확인 및 선택한 SHA-256 검증 후 목적 파일로 이름을 바꾼다. 기존 파일은 덮어쓰기 확인 없이 변경하지 않는다. SFTP 덮어쓰기는 서버의 POSIX rename 확장 지원이 필요하다.
- 일시정지는 현재 전송 연결을 중단한다. 재개 시 새 연결을 열고 실제 부분 파일 크기부터 이어 보낸다. 다운로드는 offset, FTP 업로드는 APPE/localStart, SFTP 업로드는 offset 쓰기를 사용한다. 서버가 이어받기를 지원하지 않으면 오류를 표시한다.
- 전송 중 일시적인 네트워크 실패는 최대 3회 시도한다. 인증/권한/체크섬 오류는 자동 재시도하지 않는다. 중단 후 이전 전송 시도의 늦은 응답을 무시하도록 전송 세대를 검사한다. 최종 이름변경 단계(`committing`)에서는 일시정지/취소 버튼을 제공하지 않는다. 서버에 이미 전달된 이름변경은 앱 종료로 되돌릴 수 없다.
- 원격 폴더·빈 파일 생성, 삭제, 이름변경을 지원한다. 삭제는 사용자 확인 후 진행하며 폴더는 비어 있어야 한다. SFTP에서만 chmod를 제공한다.
- SHA-256 검증은 기본 해제다. 원격 파일을 추가로 읽으므로 파일 크기만큼 추가 네트워크 비용이 발생한다.
- 비밀번호/Passphrase를 디스크에 저장하지 않는다. 입력란은 요청 시 비우며, 이어받기/네트워크 재시도용 자격증명은 활성 세션의 메모리에만 유지한다. 연결 종료 시 참조를 제거한다.
- FTP 접속에는 평문 전송 경고 확인이 필요하다. FTPS 인증서 검증을 끄는 옵션은 제공하지 않는다. 사용자 CA 선택 UI는 후속 범위다.
- 취소 시 부분 파일 삭제를 시도한다. 서버 접근 실패·탭 종료·프로세스 종료 시 부분 파일이 남을 수 있다. 큐와 재개 상태는 앱 재실행 후 복구하지 않는다.

## 8. 폴더 비교·파일 동기화

- `폴더 비교·동기화`에서 로컬→원격 또는 원격→로컬 방향을 선택한다. 현재 패널의 폴더 전체를 재귀 비교한다. 양방향 병합이나 삭제 미러링은 제공하지 않는다.
- 비교 기준은 **크기 + 수정일**(기본, 수정일 2초 오차 허용) 또는 **크기만**이다. 내용 해시 비교는 지원하지 않는다. 같은 크기·수정일의 내용 변경은 탐지하지 못할 수 있으며, 전송 후 SHA-256 검증과는 별개다.
- 미리보기는 새 항목, 변경 항목, 동일 항목, 파일/폴더 또는 심볼릭 링크 충돌, 대상 전용 항목을 보여준다. 대상 전용 항목은 유지한다.
- 확인 후 실행하면 없는 폴더를 먼저 생성하고 새 파일/변경 파일을 큐에 등록한다. 선택 방향이 덮어쓰기 기준이며, 최신 파일 자동 선택은 하지 않는다.
- 미리보기는 5분 동안 유효하고 1회 실행한다. 실행 직전 목록·메타데이터를 다시 비교하여 바뀌었으면 재검토를 요구한다. 실행 중 외부 변경까지 잠그는 기능은 없다.
- 파일 전송에서 수정일 보존을 시도한다. 다운로드는 로컬 `utimes`, SFTP 업로드는 SFTP `utimes`, FTP/FTPS 업로드는 `MFMT`를 사용한다. 서버가 지원하지 않으면 전송은 완료하고 경고를 표시한다. 이 경우 다음 비교에서 크기 기준을 선택할 수 있다.
- 폴더 준비는 파일 전송 큐 등록 전에 실행된다. 파일별 일시정지/재개/취소를 제공하며 폴더 생성 자체는 되돌리지 않는다. 폴더 단위 전체 취소·트랜잭션 롤백은 제공하지 않는다.

## 9. 일괄 이름 변경

- 로컬 또는 원격 패널의 선택 파일/폴더에 적용한다. 찾기/바꾸기는 정규식이 아닌 **리터럴 문자열 전체 치환**이다.
- 접두사·접미사와 끝 순번 `_001`, `_002`를 조합할 수 있다. 순번은 선택 순서이며 확장자 뒤까지 포함한 전체 이름 끝에 붙인다.
- 기존 이름→새 이름 미리보기를 확인한 뒤 실행한다. 빈 이름, 경로 구분자·개행·NUL, 255바이트 초과 이름, 기존 대상과의 충돌, 결과 이름 중복을 차단한다. 선택 항목끼리 이름 교환도 차단한다.
- 실행은 순차 처리한다. 중간 실패 시 완료 항목과 오류를 반환하며 자동 롤백하지 않는다. OS/서버별 대소문자·유니코드 이름 규칙에 따른 실패도 표시한다.
- 정규식 치환, 확장자 앞 순번, 재귀 이름 변경은 후속 범위다.

## 10. 예약 전송

- 선택 파일/폴더, 전송 방향, 실행 시각, 덮어쓰기 허용 여부를 지정한다. SHA-256 선택도 예약에 포함한다.
- 1초~7일 뒤의 **1회 실행**을 지원하며 연결별 예약 기록은 최대 20개다. 대기 중 예약은 취소 가능하다. 실행 시 파일을 다시 읽고 폴더를 다시 탐색한 뒤 기존 큐에 등록한다.
- 예약 상태는 대기/준비 중/큐 등록/실패를 표시한다. `큐 등록`은 전송 완료가 아니며 실제 완료는 전송 큐에서 확인한다.
- 예약·인증정보는 메모리에만 보관한다. 앱 종료, 탭 종료, 연결 종료 시 대기 예약은 취소한다. 앱 미실행 상태에서 실행, 반복 예약, OS 백그라운드 스케줄러와 예약 복구는 지원하지 않는다. 절전 중에는 깨어난 뒤 실행이 지연될 수 있다.

## 11. 추가 검증

- SQL·파일 관리자·폴더 워크플로 합계 25개 회귀 테스트: 폴더 재귀/빈 폴더/심볼릭 링크 제외, 비교 기준/대상 전용 보존/미리보기 변경 차단, 충돌 차단, 로컬/원격 이름 변경/부분 실패, 예약 실행/취소/종료 정리 검증.
- 실제 FTP·explicit FTPS 서버에서 재귀 업로드/다운로드, 빈 폴더, 수정일 보존, 변경 파일 동기화, 대상 전용 파일 유지, 로컬/원격 일괄 이름 변경, 예약 파일 전송, SHA-256 검증 통과.
- jsdom에서 비교 미리보기/실행, 이름 변경 미리보기, 예약 입력/취소 표시 및 기존 정렬/접속 기능 검증.

- 실제 SFTP 서버에서도 같은 폴더 재귀/수정일 보존/동기화/일괄 이름 변경/예약/SHA-256 시나리오 통과.
- macOS Electron에서 실제 FTPS 연결로 비교 미리보기→동기화 실행, 원격 일괄 이름 변경, 예약 입력 폼, 전송 큐 글자 대비를 확인했다. Windows 설치본 검증은 남아 있다.
