## 2. 와이어프레임

```
┌───────────────────────────────────────────────────┐
│ [prod-web-01] [prod-db-01] [+]                     │
├───────────────────────┬───────────────────────────┤
│ root@prod-web-01:~#    │ root@prod-web-01:~#        │
│ tail -f /var/log/nginx │ htop                        │
│ ...                     │ ...                         │
│                         ├───────────────────────────┤
│                         │ root@prod-web-01:~#        │
│                         │ df -h                       │
├───────────────────────┴───────────────────────────┤
│ ⌘D 세로분할 · ⌘⇧D 가로분할 · ⌘[/] pane 이동           │
└───────────────────────────────────────────────────┘
```

- 하나의 탭(= 하나의 SSH 접속) 안에서 여러 tmux pane을 동시에 표시 — 서버 측 `tmux split-window`와 1:1 대응
- pane 크기는 경계선 드래그로 조절, 포커스된 pane은 테두리로 강조
- 분할 레이아웃(몇 개, 배치)은 **클라이언트 로컬 프리셋**으로 저장해 재접속 시 자동 복원 — 단, 이는 화면 배치일 뿐 서버 tmux 세션 자체와는 무관
- 01_SSH의 동시 입력 모드(F-208~212, S8)는 "탭" 단위였다면, 여기서는 "pane" 단위로도 동일한 동시 입력을 적용할 수 있다

## 3. 기능 명세 (F-801 ~ F-806)

| ID | 요구사항 | 비고 |
|---|---|---|
| F-801 | 하나의 탭 내에서 터미널을 가로/세로로 분할할 수 있다 | 서버 tmux `split-window` 연동 |
| F-802 | 단축키로 pane 간 포커스를 이동할 수 있다 | `⌘[` / `⌘]` 또는 방향키 조합 |
| F-803 | 분할 레이아웃을 로컬에 저장하고 재접속 시 동일하게 복원한다 | 서버 tmux 상태와 독립된 "클라이언트 레이아웃 프리셋" |
| F-804 | pane 경계를 드래그해 크기를 조절할 수 있다 | |
| F-805 | 01_SSH의 동시 입력 모드(F-208)는 pane 단위 선택에도 동일하게 적용된다 | |
| F-806 | pane을 닫아도 서버 tmux pane은 유지되며, 앱 종료 시에는 F-502에 따라 모든 pane의 클라이언트 연결이 강제 종료된다 | 00_공통 F-502 원칙 승계 |
