## 1. 목표와 결정 사항(요약)

| # | 결정 | 내용 |
|---|---|---|
| D1 | 분할 방법 | **탭을 끌어서 다른 탭의 화면 위에 놓으면** 놓은 가장자리 방향(좌/우/상/하)으로 합쳐진다. SSH뿐 아니라 Web·SQL·SFTP·RDP·VNC 모두 가능 |
| D2 | 기존 SSH 분할 제거 | pane 분할 버튼(세로/가로), pane 헤더의 "— 서버/세션 선택 —" 선택기, `⌘D`/`⌘⇧D` 분할 단축키를 제거한다. 같은 서버를 나란히 보려면 **새 탭을 하나 더 열어 끌어다 놓는다** |
| D3 | 합쳐진 탭 | 합쳐진 탭 묶음은 탭바에 **하나의 탭**으로 보이고 이름은 **`그룹탭1`, `그룹탭2` …** 로 자동 지정된다. 탭 이동(`⌘1~9`, `⌘<` `⌘>`)은 이 탭 단위로 동작한다 |
| D4 | 칸 헤더 | 합쳐진 각 칸 위에는 작은 이름 띠(칸 헤더)가 있고, 여기에 **동시 입력 체크 · 재연결(새로고침) · 닫기**가 들어간다(SSH 탭바 현재 모양과 동일한 요소) |
| D5 | 저장 안 함 | 분할 구성은 **저장하지 않는다**(앱을 다시 켜면 평소처럼 개별 탭). 레이아웃 프리셋은 2차 |
| D6 | 복원 방법 | **칸을 드래그해서 빼내면** 그 칸이 다시 독립 탭이 된다 — 저장/복원 규칙 대신 이것 하나만 둔다 |
| D7 | 1차 범위 | 끌어서 합치기, 경계 드래그로 크기 조절, 칸 닫기, 칸 빼내기, 그룹탭 이름 변경. (저장·프리셋·창 간 합치기·그룹 통째로 새 창은 2차) |
| D8 | 그룹탭 이름 | 기본 `그룹탭N`이고, **그룹탭을 더블클릭하면 이름을 직접 수정**할 수 있다(Enter 확정 · Esc 취소 · 비우면 기본 이름으로) |
| D9 | 칸 이동 단축키 | **macOS `⌘⌥+방향키` · Windows `Ctrl+Alt+방향키`** (그룹탭이 활성일 때). 한도는 **칸 최대 6개, 칸 최소 280×180px**로 확정 |
| D10 | 탭 분리와의 구분 | 탭을 끌어 **창 안(내용 영역)** 에 놓으면 분할, **창 밖**으로 끌어내면 새 창으로 분리(기존 탭 분리 유지) |

## 4. 기능 명세 (F-1301 ~ F-1318)

### 4-1. 합치기(드래그 앤 드롭)

| ID | 기능 | 비고 |
|---|---|---|
| F-1301 | 탭바의 탭을 끌어 **다른 탭의 화면 영역** 위에 올리면 좌/우/상/하 드롭 영역이 표시되고, 놓으면 그 방향으로 분할되어 두 세션이 한 화면에 나란히 보인다 | 프로토콜 제한 없음(SSH·SQL·SFTP·RDP·VNC·Web 모두, 서로 다른 프로토콜 조합 가능) |
| F-1302 | 놓는 위치는 대상 칸의 **가장자리 25%** 영역으로 판정한다. 좌/우 = 좌우 분할, 상/하 = 상하 분할. **가운데 영역에서는 놓아도 아무 일도 일어나지 않는다**(교체·바꾸기 없음) | 드롭 영역은 반투명 강조색으로 미리 보여준다 |
| F-1303 | 이미 합쳐진 그룹탭의 칸 위에 놓으면 **그 칸을 분할**한다(좌우·상하를 섞어 중첩 분할 가능) | 레이아웃은 분할 트리로 관리 |
| F-1304 | 자기 자신 위에 놓거나, **그룹탭 자체를 끌어 다른 탭/그룹 위에 놓는 것은 1차에서 허용하지 않는다**(드롭 영역이 나타나지 않음) | 그룹끼리 합치기는 2차 |
| F-1305 | 한 그룹탭에 넣을 수 있는 칸은 **최대 6개**, 한 칸의 최소 크기는 **너비 280px × 높이 180px**. 이 한도를 넘기게 되는 방향은 드롭 영역이 비활성(회색)으로 표시된다 | 값은 상수로 두어 조정 가능하게 한다 |
| F-1306 | 합쳐지면 원래 있던 개별 탭은 탭바에서 사라지고 **`그룹탭N`** 하나가 그 자리에 생긴다(N은 현재 창에서 1부터 순서대로, 해제된 번호는 재사용). 이미 그룹탭이 있는 곳에 합쳤다면 그 그룹탭이 그대로 유지된다 | 그룹탭에 마우스를 올리면 포함된 세션 이름 목록을 툴팁으로 보여준다 |
| F-1306a | **그룹탭을 더블클릭하면 이름을 수정**할 수 있다. Enter로 확정, Esc로 취소, 빈 값으로 확정하면 기본 이름(`그룹탭N`)으로 돌아간다. 최대 20자 | 이름은 저장하지 않는다(F-1317) |
| F-1307 | 합치는 동안 세션은 **끊기지 않는다**. 세션 객체는 그대로이고 표시 위치만 바뀐다 | SSH·RDP·VNC·SFTP·SQL 연결 유지, Web은 `<webview>`를 옮기지 않고 화면 위치만 바꾼다(페이지·로그인 상태 유지) |

### 4-2. 칸 조작

| ID | 기능 | 비고 |
|---|---|---|
| F-1308 | 각 칸은 **칸 헤더**를 가진다 — 프로토콜 아이콘 · 서버 이름 · 상태 점 · (해당되는 칸만) 동시 입력 체크박스 · 재연결 버튼 · 닫기(×) | 헤더 모양은 현재 SSH pane 헤더와 탭 안의 작은 이름 띠를 따른다 |
| F-1309 | **동시 입력 체크박스는 SSH 칸에만** 표시한다. 체크하면 01_SSH의 동시 입력(F-208) 대상에 그 칸의 세션이 포함되고, 칸 헤더에 빨간 테두리를 표시한다(탭의 동시 입력 표시와 동일). 그룹탭 자체에는 체크박스를 두지 않는다 | 분할되지 않은 일반 SSH 탭은 지금처럼 탭에 체크박스를 둔다 |
| F-1310 | **재연결(새로고침) 버튼**은 `hasConnAction`(재연결 개념이 있는 프로토콜 — SSH 등)인 칸에만 표시한다. 누르면 그 칸의 세션만 재연결한다 | 다른 칸에는 영향 없음 |
| F-1311 | 칸 사이의 **경계를 드래그해 크기를 조절**한다. 최소 크기(F-1305) 아래로는 줄어들지 않는다 | RDP/VNC 칸은 드래그 중에는 화면 크기 변경을 보내지 않고 **손을 뗀 뒤**에 한 번만 반영한다(재협상 남발 방지) |
| F-1312 | 칸 헤더의 **×는 그 칸의 세션만 종료**하고 칸을 제거한다. 칸이 1개만 남으면 그룹이 자동 해제되어(F-1314) 평소 탭으로 돌아간다 | 연결 중인 세션을 닫는 것이므로 SSH·RDP·VNC·SQL·SFTP는 확인 없이 닫되, 전송 중인 SFTP 작업이 있으면 확인 창을 띄운다 |
| F-1313 | 칸을 클릭하거나 그 칸 안에서 입력하면 **그 칸이 포커스를 받는다**. 포커스 칸은 헤더를 강조색으로 표시한다. 키보드 입력·인스펙터(연결 정보 패널)·빠른 연결 주소 바는 **포커스 칸**을 기준으로 동작한다 | 동시 입력이 켜져 있으면 포커스 칸이 아니라 체크된 SSH 칸 전체에 입력이 전달된다(01_SSH 동일) |

### 4-3. 복원(빼내기) — 저장 규칙 대신

| ID | 기능 | 비고 |
|---|---|---|
| F-1314 | **칸 헤더를 끌어 탭바 위에 놓으면** 그 칸이 독립 탭으로 빠져나온다(세션 유지). 남은 칸이 1개가 되면 그룹은 자동으로 해제되고 그 칸은 원래 이름의 일반 탭으로 돌아간다. 해제된 `그룹탭N` 번호는 재사용된다 | 이것이 유일한 복원 방법이다 |
| F-1315 | 칸 헤더를 끌어 **창 밖(탭바 밖)** 으로 가져가면 기존 탭 분리와 동일하게 그 칸의 세션이 **새 창의 탭**으로 옮겨진다(세션 유지 가능 범위는 프로토콜별 기존 규칙을 따름 — Web은 URL·쿠키만 유지) | 기존 탭 분리·병합 규칙 승계 |
| F-1316 | **그룹탭을 닫으면(탭의 ×, 상단 닫기 버튼) 포함된 모든 세션이 종료**된다. 연결 중인 세션이 있으면 "그룹 안의 N개 세션이 모두 종료됩니다" 확인 창을 띄운다 | 그룹이 1개 칸이면 일반 탭 닫기와 같다 |
| F-1317 | **저장·복원은 하지 않는다.** 앱을 종료하면 그룹/분할 구성은 사라지고, 서버 목록(F-602)은 지금처럼 복원되며 탭은 평소처럼 비어 있는 상태로 시작한다 | 레이아웃 프리셋은 2차 |
| F-1318 | **1차에서는 그룹탭 통째로 새 창에 옮기지 않는다**(그룹탭을 창 밖으로 끌어도 분리되지 않음 — 칸을 하나씩 F-1315로 빼면 된다). 다른 창의 탭을 현재 창의 분할에 합치는 것(창 간 합치기)도 1차에서는 지원하지 않는다 | 그룹 통째 분리·창 간 합치기는 2차 |

## 5. 탭 이동·단축키 규칙

| 대상 | 규칙 |
|---|---|
| `⌘1~9` (Win: `Ctrl+1~9`) | **탭바의 N번째 탭**으로 이동한다. 그룹탭은 칸 개수와 관계없이 탭 **1개**로 센다 |
| `⌘<` `⌘>`, `Ctrl+Tab` | 탭바 기준으로 **이전/다음 탭**(그룹탭 포함)으로 이동한다. 칸 사이 이동이 아니다. (`⌘⌥←/→`는 일반 탭에서만 같은 동작, 그룹탭에서는 칸 이동) |
| 그룹탭으로 이동 시 | 마지막에 포커스가 있던 칸이 다시 포커스를 받는다(처음이면 왼쪽 위 칸) |
| 칸 사이 포커스 이동 | **macOS `⌘⌥+방향키` / Windows `Ctrl+Alt+방향키`** — 그룹탭이 활성일 때 그 방향에서 가장 가까운 칸으로 포커스를 옮긴다. 터미널 포커스 중에도 앱이 먼저 가로채며(셸로 전달되지 않음), 그룹탭이 아닌 일반 탭에서는 기존처럼 `←/→`가 이전/다음 탭 이동으로 동작한다. 선택 이유: iTerm2·Windows Terminal의 칸 이동 관습과 같은 계열이고, 앱의 "⌘ = Windows의 Ctrl" 규칙과 일치하며, 셸·webview의 Alt+방향키(단어 이동·뒤로 가기)와 겹치지 않는다 |
| 상단 "현재 탭 닫기"(×) | 활성 **탭 전체**를 닫는다(그룹탭이면 F-1316). 칸 하나만 닫으려면 칸 헤더의 ×를 쓴다 |
| `⌘I`(연결 정보), `⌘B`(서버 목록 접기) | 기존과 동일. 연결 정보 패널은 **포커스 칸**의 서버를 보여준다 |
| `⌘K`(빠른 연결/검색) | 열린 세션은 **포커스 칸이 있는 그룹이 아니라 새 일반 탭**으로 열린다(칸 안에 자동으로 끼워 넣지 않음) |

## 6. 프로토콜별 크기 대응 요구사항

칸 크기가 바뀌어도(합치기·경계 드래그·창 크기 변경) 각 세션 화면이 칸을 정확히 채워야 한다.

| 프로토콜 | 요구사항 |
|---|---|
| SSH | 칸 크기 변화에 맞춰 터미널 열·행을 다시 맞춘다(기존 fit 로직 재사용) |
| RDP | 칸 크기 변화에 맞춰 원격 해상도를 변경한다(05_RDP의 동적 해상도). 경계 드래그 중에는 보내지 않고 손을 뗀 뒤 한 번만(F-1311). 실제 크기 모드(스크롤)는 기존대로 변경 요청 안 함 |
| VNC | 칸 안에서 화면을 비율 유지로 맞춰 보여준다(원격 해상도는 바꾸지 않음) |
| Web | `<webview>`가 칸 전체를 채운다(칸 높이가 내용 높이로 줄어드는 문제가 없어야 한다 — QA 18번 재발 방지) |
| SQL / SFTP | 칸이 좁아져도 가로 스크롤 또는 접힘으로 깨지지 않는다. 최소 크기(F-1305)에서도 조작 가능 |
| 빠른 연결 주소 바 | 탭 위 전역 바이므로 **포커스 칸의 서버가 빠른 연결(temp)일 때** 표시한다 |

## 7. 데이터 모델(런타임, 비영속)

```
Tab         { id, title, kind: 'single' | 'group', ... }       // 탭바 항목
GroupTab    { id, title: '그룹탭N', root: SplitNode, focusedCellId }
SplitNode   = Cell | { orientation: 'row'|'column', children: SplitNode[], sizes: number[] }   // 비율 합 = 1
Cell        { id, sessionTabId, protocol }                     // 세션은 기존 tabId 그대로 사용
```

- 세션(`sessionTabId`)은 합치기 전과 같은 값을 쓴다 → 메인 프로세스의 세션 등록·IPC 이벤트가 그대로 동작한다.
- 동시 입력 대상(`broadcastSet`)은 칸의 세션 id를 그대로 넣는다 — 일반 탭이든 칸이든 같은 집합으로 관리한다.
- 앱 종료/창 닫기 시 저장하지 않는다(F-1317).

## 9. 완료 기준(체크리스트)

- [ ] SSH 탭을 Web 탭 화면 위로 끌어 좌/우/상/하로 놓으면 해당 방향으로 합쳐지고 두 세션이 끊기지 않는다(F-1301~1302, F-1307)
- [ ] 가운데에 놓으면 아무 일도 일어나지 않고, 그룹탭을 그룹/탭 위에 놓는 드롭은 막힌다(F-1302, F-1304)
- [ ] 합쳐진 탭이 `그룹탭1`로 탭바에 1개만 보이고, 두 번째 그룹은 `그룹탭2`가 된다(F-1306)
- [ ] 칸 6개/최소 크기 한도에서 드롭 영역이 비활성으로 보인다(F-1305)
- [ ] 칸 헤더에 동시 입력(SSH만)·재연결·닫기가 있고, 동시 입력 체크한 칸은 빨간 테두리가 보이며 체크된 칸 전체에 입력이 전달된다(F-1308~1310)
- [ ] 경계를 끌어 크기를 조절할 수 있고 RDP는 손을 뗀 뒤 한 번만 해상도가 바뀐다(F-1311)
- [ ] 칸 ×로 그 세션만 종료되고, 1칸이 남으면 일반 탭으로 돌아간다(F-1312)
- [ ] `⌘1~9`, `⌘<` `⌘>`이 그룹탭을 탭 1개로 세어 이동하고, 돌아오면 마지막 포커스 칸이 유지된다. `⌘⌥+방향키`(Win `Ctrl+Alt+방향키`)로 칸 사이를 이동한다(5장)
- [ ] 그룹탭을 더블클릭해 이름을 바꿀 수 있고 Esc로 취소된다(F-1306a)
- [ ] 칸 헤더를 탭바로 끌면 독립 탭으로 빠지고 세션이 유지된다. 칸이 1개 남으면 그룹이 해제된다(F-1314)
- [ ] 칸을 창 밖으로 끌면 새 창으로 옮겨진다(F-1315). 그룹탭 통째 분리는 1차 범위 밖(F-1318)
- [ ] 그룹탭 닫기 시 "N개 세션 종료" 확인 후 모든 세션이 종료된다(F-1316)
- [ ] 앱을 다시 켜면 분할 구성이 복원되지 않는다(F-1317)
- [ ] 모든 프로토콜 칸이 칸 크기를 정확히 채운다(6장)

## 10. 범위 밖(2차 이후)

- 분할 구성(레이아웃 프리셋) 저장·불러오기, 앱 재시작 시 복원
- 그룹탭끼리 합치기, 다른 창의 탭을 현재 창 분할에 합치기(창 간 합치기)
- 가운데 드롭으로 칸 교체/위치 바꾸기, 칸 위치 드래그로 재배치
- 칸 최대화/복원 토글, 그룹 통째로 새 창 이동

## 11. 확정된 사항(구현 기준)

1. 칸 이동 단축키: macOS `⌘⌥+방향키`, Windows `Ctrl+Alt+방향키`(5장).
2. 칸 최대 6개, 최소 280×180px(F-1305).
3. 그룹탭 이름은 `그룹탭N`이 기본이고 더블클릭으로 수정 가능(F-1306a).
4. 탭을 끌어 창 밖으로 내보내면 새 창으로 분리, 창 안 내용 영역에 놓으면 분할(D10) — 이전처럼 탭바에서 아래로 살짝만 끌어도 분리되던 동작은 없어진다.
