# Web 콘솔 기능 명세 — URL 등록(북마크)

> 상위 문서: [../기획서.md](../기획서.md) · 공통 원칙: [00_공통_기능명세.md](./00_공통_기능명세.md)
> 상태: ✅ 구현 완료 (`src/renderer/protocols/web/`, `src/main/protocols/web/`)
> Web 콘솔은 별도 화면이 없다 — **S2 등록 모달(00_공통)에서 프로토콜을 "Web"으로 선택하면 그대로
> 등록/편집되고, S7 관리 테이블에서도 동일하게 다뤄진다** (이미 UI 목업에 구현됨).

| ID | 요구사항 | 비고 |
|---|---|---|
| F-1101 | 서버 목록에 URL을 프로토콜 "Web"으로 등록할 수 있다 | S2/S7 재사용, 새 화면 없음 |
| F-1102 | 클릭 시 기본 브라우저 또는 내장 웹뷰로 해당 URL을 연다 | |
| F-1103 | 계정 자동입력(ID/PW 자동채움)은 지원하지 않는다 — 북마크 용도로 한정 | 00_공통 F-609(자동로그인 금지)와 동일 원칙 적용 |

## 3. 구현 메모

- 탭을 열면 내장 `<webview>`로 URL을 표시하고, 툴바의 "브라우저로 열기"로 기본 브라우저에서도 연다(F-1102).
- 호스트 입력에 스킴(`http://`, `https://`)이 있으면 그대로 사용한다. 없으면 포트가 비었거나 443/8443/9443이면 https, 그 외 포트는 http로 연다. http/https 외 스킴은 열지 않는다.
- 웹뷰 파티션은 `persist:` 없는 탭별 메모리 전용이라 쿠키/세션이 디스크에 남지 않는다(F-1104).
- 웹뷰 부착은 메인 프로세스(`will-attach-webview`)에서 검증한다: preload 제거, Node 접근 차단, 영속 파티션 거부, http(s)만 허용. 웹뷰 안의 새 창 요청은 기본 브라우저로 넘긴다.
- 확인한 것: Electron 실행 후 Web 서버 탭에서 https://example.com 로드, 사이드바 상태 점 on, 탭 닫기 시 웹뷰 제거 및 상태 점 off.
- 인증서를 신뢰할 수 없는 사이트(자체 서명 등)는 기본 차단하고, 탭 안에 원인을 표시한다. "위험을 감수하고 이 탭에서만 계속"을 누르면 그 탭(웹뷰)·그 호스트에 한해 인증서 오류를 통과시키며, 허용 내역은 메모리에만 두고 저장하지 않는다. 로드 실패는 인증서 외에도 오류 코드와 함께 표시한다.
