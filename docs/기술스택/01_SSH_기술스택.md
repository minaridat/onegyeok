# SSH 기술 스택 — `ssh2`

> 메인 기술 스택: [00_메인_기술스택.md](./00_메인_기술스택.md) · 기능 명세: [../기능명세/01_SSH_기능명세.md](../기능명세/01_SSH_기능명세.md)
> 상태: ✅ 적용됨 — `src/main/ssh-manager.js`

- Node.js용 SSH2 프로토콜 구현체. 터미널 셸, exec, SFTP, 포트포워딩을 모두 지원해 **SSH·SFTP 연동을 하나의 의존성으로 커버**할 수 있다.
- `node-ssh`는 `ssh2`를 감싼 Promise 래퍼일 뿐이라 굳이 추가 의존성을 둘 필요는 없다고 판단 — `ssh2`를 직접 사용.
- tmux 등 세션 유지 도구는 앱이 자동으로 실행하지 않는다([01_SSH_기능명세.md](../기능명세/01_SSH_기능명세.md) F-205/206 — 같은 이름의 세션에 여러 탭이 몰려 다중 세션이 막히고, tmux 미설치 서버에서는 접속 직후 명령이 실패하는 문제가 있어 폐기). 필요하면 사용자가 셸에서 직접 실행한다.
- 터미널 화면 렌더링은 `xterm.js`(렌더러 프로세스) + `ssh2`의 데이터 스트림을 IPC로 중계하는 구조로 구현됨.
- 인증 실패/네트워크 오류 분류(`classifySshError`)로 "재입력하면 될 수도 있는 오류"(`auth`/`badkey`)와 "재입력해도 의미 없는 오류"(`network`/`other`)를 구분해, 전자만 ssh 명령어처럼 그 자리에서 재시도시킨다.
