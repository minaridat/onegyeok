onegyeok — 메인 화면 (탭 중심 구성)

맨 왼쪽 아이콘 레일이 Orca의 워크트리 전환기처럼 "전체 · SSH · RDP · VNC · SFTP · Web" 컨텍스트를 전환합니다. 전체에서는 모든 프로토콜의 탭을 자유롭게 섞어서 오갈 수 있고, 특정 프로토콜을 클릭하면 사이드바와 탭이 그 프로토콜만 걸러져 보입니다(세션은 유지된 채 화면만 필터링). 탭 전환 단축키 힌트는 왼쪽 서버 검색창 바로 아래에 있고, 오른쪽 "연결 정보" 패널은 topbar 아이콘이나 패널 안 화살표로 접었다 펼 수 있습니다. SSH는 Phase 1부터, 나머지는 Phase 배지로 로드맵을 표시합니다. 상단의 [서버 관리] 버튼을 누르면 등록된 서버 전체를 테이블로 조회·검색·정렬하고 바로 수정/삭제할 수 있는 화면(S7)이 열리고, 여기서도 그룹을 새로 만들 수 있습니다. 사이드바·연결정보 패널 경계선을 끝까지 드래그하면 패널이 접히고, 레일의 전체/프로토콜 버튼을 누르면 접혔던 사이드바가 다시 펼쳐집니다. 탭이 많아 넘치면 좌우 화살표로 스크롤되고, 연결 정보 패널 위쪽의 "연결정보"/"메모" 탭을 눌러 서버 메모장을 전환할 수 있습니다.
